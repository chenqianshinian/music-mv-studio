# 多关键帧垫图策略（防伪影的核心手段）

## 每镜关键帧数量

| 镜头类型 | 关键帧数 | 说明 |
|---|---|---|
| 静态风景/氛围 | 1-2 | 起-落 |
| 人物特写/表情 | 2-3 | 表情起势-落点（如"眼含离愁"→"坚定"） |
| 动作镜（飞行/转身/俯冲/起飞） | 3-4 | 起势-过程-落点 |
| 群像/双线同框 | 3 | 位置/朝向锁定 |
| 变身/揭面/反转 | 3 | 前-中-后 |

## Agnes keyframes 模式（实测有效格式）

```json
{
  "model": "agnes-video-v2.0",
  "prompt": "动作描述（起→中→落）",
  "width": 768, "height": 1344,
  "num_frames": 121, "frame_rate": 24,
  "negative_prompt": "...",
  "extra_body": {"mode": "keyframes", "image": [url1, url2, url3]}
}
```

要点：
- **不传顶层 image**，图片列表只放 `extra_body.image`
- 图床 uguu 上传后必须逐个验证 200（偶发 404）
- 转圈/头身同步问题只有关键帧模式能根治（单首帧必然头身不同步）

## 生成器断点与守护

- 状态文件：`<outdir>\<bank 名>-gen-state.json`；重跑自动跳过已完成
  （多路并行时用 `--state-tag` 给每路一个独立后缀，避免互相覆盖）
- API 503/queue_full/429：用守护循环重启（supervise 模式），每轮间隔 5 分钟
- 关键帧下载校验：文件能打开（PIL）才算成功，失败重下
- 每个提交任务前先写状态，崩溃可恢复

## 候选与筛选

- 每镜 3 候选；按 表情准确性 > 解剖完整 > 运动自然 > 风格一致 排序
- 表情/结构不合格的候选直接弃用重生成，不将就

## 首帧闸门要"量"，不要"看"（v2.1 新增，2026-09-24）

目视放行踩过两次：
- `A1-10`：要求"人物合计不超过画面高度的 1/10"，目视过关，实测**占 1/2**，而且两人正对镜头朝镜头骑来。
- `M-3`：要求"整幅画面只有一位年轻男生"，以为过关，**只数人头 = 2**。

所以首帧过闸门必须让视觉模型给**数字与固定字段**（占比、人头数、有无脸、朝向），合格才开视频。人数不一致时先"只数人头"复核一次——模型会把一个人的上下身拆成两个"人形"（M-3 首帧就这样被误判过）。

## 方向锁：首帧 + 派生帧（v2.1 新增）

1. **首帧锁方向**：行进方向、面向哪里、在画面里多大，全部写进关键帧提示词，并在提示词**头尾各重复一次**（模型对尾部约束更敏感）。首帧方向错了，重出首帧是唯一解。
2. **派生帧（kf1x）锁方向**：管线是在"首帧 ↔ 派生帧"之间插值，所以派生帧是**用图钉方向**的最强杠杆。要求：派生帧提示词里**单独写一句"人物向前推进到哪里"**。
3. **坑**：`gen_zuindongni.py` 的 `derive_kf1()` 现在只取 i2v 提示词的**第一句话**当"画面推进"。动作镜的第一句往往是"整幅画面以某环境为主体"这类空镜描述，方向信息在这一步被静默丢掉（`A1-10` 就是这样）。→ 待修：让派生帧吃专门的"动作/方向推进"字段。
4. **候选排序增加两个维度**：`方向正确 > 人数稳定 > 素材内无突变`，排在原来的"表情/解剖"之后、风格一致之前；用 `pick_v4d.py` 自动跑这三道，不合格候选一律不选、单镜重出，**不许硬渲**。
