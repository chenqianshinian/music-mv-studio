# 提示词规范（五段式 + 反伪影负向词表）

## 五段式提示词模板

```
1 角色卡：写实拟人/唯美动漫 [物种/人物] + 服装 + 特征（跨镜锁定毛色/发色/服饰）
2 表情眼神：精确到"瞳孔收缩/眯眼假笑/嘴角微扬不露齿/眼含泪光"级别
3 动作起落：写明起势→过程→落点（如"振翅腾空，翅膀完全展开，升入云端"）
4 场景光影：环境 + 光线（诱饵光/清醒光/逆光/晨昏光）+ 时间感
5 画质：电影写实摄影/唯美漫画国风 + 35mm/动漫渲染 + 无文字无水印
```

## 比例与解剖硬约束（写入每条关键帧提示词）

- 比例：明确物体大小关系（"雁比扁舟小得多""人物占画面高度比例不超过 1/3"）
- 解剖负向词表（negative_prompt 必含）：

  ```
  double neck, two necks, extra neck, deformed neck, no neck,
  double wings, extra wings, deformed wings, broken wings,
  extra limbs, wrong paw count, fused fingers, broken limbs,
  distorted face, warped features, asymmetric eyes, wrong proportions,
  giant animal, oversized animal, human-sized bird,
  cropped head, morphing body, distorted eyes, duplicate body parts
  ```

- 表情负向词（人物）：`grinning, wide smile, open mouth laugh, creepy smile, horror face`

## 国风人物表情卡（婉约系）

- 默认：`婉约浅笑，嘴角微微上扬不露齿，眼含温柔`
- 离别：`眼含离愁，目光柔和带一丝不舍，嘴角克制地微扬`
- 期待：`眼神明亮，含着希冀与期盼，眉眼舒展`
- 坚定：`目光坚定平静，下颌微收，表情从容`
- 禁止：`咧嘴大笑、瞪眼、惊悚、夸张表情`

## 动态防静态规则

- i2v 运动提示词必须含动词过程（起→中→落），禁止只有形容词
- 每镜生成后抽帧测帧间差：<8 判为静态，必须重生成

## H3 提示词结构吸收（2026-08-21，来自 MiniMax-AI/MiniMax-H3 h3-prompt-writing skill）

### 三字段结构（借鉴到 i2v 提示词）

H3 官方把提示词分为三字段，我们 Agnes 只支持单 prompt，但可以把"画面+镜头+动作"的组织方式学过来：

- **镜头运动三要素**：类型 + 幅度 + 速度。类型用标准词：`push in / pull out / pan left / truck right / tilt up / pedestal down / arc shot / tracking shot / static shot / POV`；幅度 `with small/large amplitude`；速度 `at slow/fast speed`。写法：`The camera pushes in with small amplitude at slow speed`，写进 i2v 提示词的镜头段。
- **镜头切换语义**：普通切换用 `the camera cuts to`；切镜头必须带来新信息（主体/空间/状态/视角/时间之一变化），只是距离变化时用运镜不用切。
- **首尾帧描述结构（FL2VA 版，对应我们的尾帧垫图链）**：`首帧状态 → 可观察的中间变化 → 逐渐收窄的差异 → 尾帧状态`。我们链式镜头（chain_prev）的 i2v_prompt 要按这个结构写，而不是只写"动作流畅自然"。
- **静态镜头明确标注**：`The camera holds a static shot` 只用于需要静谧的时刻（如凝望），其余默认有运镜。

### 多镜头拼接细则吸收（来自 music-video-subtitle-generator skill）

- **鼓点硬切**：副歌进入处、情绪转折点用硬切（cuts to），不用交叉淡化——硬切是节奏工具。
- **Match Cut**：换场景但保持同向运镜或视觉元素匹配（如 A 镜向右 pan 结束，B 镜从向右 pan 开始）。
- **镜头时长 2-5 秒组**：长歌词句不硬撑一镜，拆 2 个短镜用鼓点或动作衔接。
- **全局主音轨对齐**：先锁完整歌曲，所有镜头按歌词时间戳卡拍（我们已按 SRT 对齐，保留）。

## 音乐 MV 拼接工作流（与 music-video-subtitle-generator 印证，升级为硬规则）

- 尾帧垫图链（已有）＝ 官方"首尾帧接续"（Tail Frame → Head Frame）
- 新增：**副歌进入处一律硬切**（cuts to），段内连续动作用链式垫图
- 新增：**换场景用 Match Cut**（同向运镜或同一视觉元素过渡），禁止无锚点跳切
- 屏幕文字是设计图层（挥毫字幕已是，保留）
- 歌词锁定：用户提供的歌词是唯一源文本，不改写、不增减（已有，保留）

## 【方向锁】与运动类负向词（v2.1 新增，2026-09-24《老一辈的爱情》）

### 为什么必须单独立这一节

体型类负向词（双头/多脖子/多出一只手/手指融合）从 2026-08 就写全了，所以**畸形类毛病被压住了**；但"倒退走、倒放、反向、原地踏步、车轮倒转"这些**运动类词一条都没有**，105 镜的 i2v 提示词里也**一次没出现**——于是"方向类"毛病一路反复，直到用户第三次提意见。**方向要在首帧与第二关键帧锁，提示词只做第二层。**

### 每条动作镜的 i2v 提示词末尾追加（按镜改数字，别复制粘贴）

```
【方向锁】整段运动方向自始至终一致，不出现倒退走、倒退骑、倒放、反向移动、
原地踏步、反复横跳或脚在动而身体反向移动；人物一律朝画面<左侧/右侧/深处>前进；
车轮/道具始终朝前进方向单方向滚动，绝不倒转。
```

### 单车/载具镜额外加（这类最常翻车）

```
【载具锁】只有前面扶车把的人在踩踏板；后座的人双脚放在车架脚踏/横梁上保持不动，不踩踏板；
车身朝前进方向前进，不倒退、不后滑。
```

### 静止镜（两人站定/空镜）要反着锁

```
【画面锁】人物始终站在原处，全程只有衣角、雪粒、影子、浮尘与镜头极缓前推的变化；
不出现任何人向前或向后移动、不倒退走、不原地踏步。
```

《老一辈的爱情》C1-6 就是设计成"两人站定"却被生成成有位移与倒退，所以静止镜也必须显式锁，不能默认"不动"。

### negative_prompt 必加（运动类，目前全缺）

```
倒退, 倒放, 反向移动, 向后倒退走, 原地踏步, 反复横跳, 来回抖动,
车轮倒转, 车轮反转, 车辆倒滑, 脚步方向与行进方向相反, 肢体反向运动
```

### 配套：方向必须在首帧锁死（否则提示词无效）

实测反例（《老一辈的爱情》）：

- `A1-10` 提示词写着"远景小剪影、背对镜头骑远、看不到脸"，首帧却是两张清晰的脸正对镜头、朝镜头骑来 → 成片一路朝镜头骑。
- `A2-1` 提示词写着"朝画面深处骑远"，成片"往前蹬车、往后倒"。
- `M-3` 要求"整幅画面只允许出现一位年轻男生"，上一轮首帧只数人头 = 2。

**判定口径**：只要首帧的朝向/行进方向与设计不符，就重出首帧——不要指望文字去扭转已经定型的动作。

## 内容前置：风格词的位置（v3.3 修正，推翻旧口径）

旧口径是"风格必须前置"——它来自写实题材（风格写句尾时，模型先按题材画成写实或 3D）。
换成动漫/插画媒介后它会反噬。

实测（第 9 首情绪关键帧，8 张全中）：

- 提示词以「日本动画电影质感（剧场版）」＋一长串风格尾（布光/景深/颗粒/写实比例）**开头** ⇒
  模型切进"动画海报"模式，**丢掉后面整段场景描述**：8 张全被画成「室外草地＋日式民居＋
  多名校服学生站着」；本该暖金的那张 warm 像素只占 **10%**、cool 占 **34%**。
- 把内容提到前面、风格尾缩到一句、末尾复述主体并排掉群像/海报 ⇒ 同一批提示词立刻回到设计稿。

**现行配方（照抄顺序）**：

```
日式手绘动画。<媒介＋人数＋动作>。<场景与光影>。<短风格尾>。
硬性要求：只画下面描述的这一个／两个人、这一件事，不是群像、不是海报、不要多人并排、
不是照片、不是真人实拍、不是 3D 渲染、不是厚涂油画。
画面人数：<该镜到底几个人；无人镜写"不出现任何人物，也不出现任何手、胳膊、腿或肢体">
```

- 开头只留**一个短媒介词**（「日式手绘动画」），不是整条 `_meta.style_prompt`；
- 风格尾**后置且短**；
- **末尾复述主体**（这一条最省事、最有效：模型对提示词首尾都敏感）；
- 显式排掉的清单固定挂一句：群像 / 海报 / 多人并排 / 校服学生 / 瓦片房顶 / 多人站在草地上（§5 #60）。

## 画面里的汉字：提示词留白 ＋ 过闸门后代码烧（v3.3 新增）

**永远不要让出图模型写汉字**（§5 #25 的同源结论）：提示词里写"纸上写着『自由』"必出乱码。

两步工艺：

1. **出图**：纸/牌在提示词里写死「空白」——"一张空白稿纸，正面几乎正对镜头、摊平而完整"
   /"一块空白的工牌，牌面平整、占画面中部一块可辨认的矩形"；先过首帧闸门。
2. **烧字**（闸门通过之后、i2v 之前）：
   - 用视觉模型问出那张纸/牌**在这张图里**的归一化包围盒（`x0,y0,x1,y1`，0–1）；
   - 用 PIL 把字贴到盒心：字号取「盒高"与"字数」两者的**小值**，毛笔楷书类字库更适合"手写感"；
   - **kf 与 kf1x 各问一次包围盒**——同一物体在两张图里的位置并不相同，共用框会把字贴歪；
   - 烧完用**单张全尺寸**复核：字可读、无乱码、确实落在纸面/牌面上。

顺序不能换：i2v 吃的是**首帧＋尾帧两张图**，只在其中一张上烧字，成片里字会在中途消失/漂移。
字幕由合成器在最上层叠加，与画面内的烧字互不干扰。

### "不要有字"该怎么写（v3.4 补，反面写法实测有效）

**不要用形状词描述"空白"**：写"只允许出现深浅色块与几道横线"**＝在教模型画表格**。
实测后果：收购单被画出表格线与多行字、土墙被贴上白纸红边对联（模型对"住宅"的先验很强）。

```text
✅ 正确：纸面是干净的空白，只有纸本身的颜色与折痕。
❌ 错误：只有深浅色块与几道横线／没有表格线／不要横线。
```

配套两条：

1. **状态代替形状**——只说"干净、空白、平整"，不要列举任何线、格、框、笔画；
2. **在场景句里排掉具名物件**——"屋角没有门框、没有红对联、没有招牌"，比在负向词里堆"no text"有效
   （出图阶段根本不发负向词，见 §6.3）。

要画面里出现汉字时，仍走"提示词留白 → 过闸门后用代码烧"的两步工艺（上一节）。
