# 分镜设计规范

## 1. 叙事四问（分镜前必答）

1. 谁是主角？（人/动物/意象；拟人设定必须先经用户确认）
2. 时间线？（一天/四季/迁徙季/一生）
3. 空间线？（从哪到哪；必须有起点-途经-终点）
4. 情绪线？（起-伏-转-合，写清每段的情绪词）

## 2. 迁徙/航拍类歌曲的标准镜头逻辑（以《秋雁又南飞》为范本）

正确的"雁南飞"叙事镜头顺序：

1. 远景：北风萧瑟，大片芦苇泛黄（环境定调）
2. 特写：大雁眼睛（个体引入）
3. 中景：群体沟通鸣叫（声音引入）
4. 全景：群体起飞（动作起点）
5. 跟拍：离水面越来越远、离云层越来越近（升空）
6. 仰视远景：人字形雁阵往南飞（主镜头）
7. 近景：女孩仰望雁阵（人间线引入）
8. 平视：村口父母背着行囊挥手告别（送别）
9. 远景：夕阳下，父母走的方向 = 大雁远飞方向（双线合一）
10. 特写：头雁（领头者）
11. 俯视：云层下景观变化 村落→大山→河流→城镇→芦苇江面（空间迁移）
12. 远景：大雁下落（抵达）

规则：任何迁徙叙事必须覆盖"起点-途中-终点"，禁止只做特写堆砌。

## 3. 自媒体黄金播放规律

- 3 秒钩子：开场 3 秒给最强画面/歌词金句/悬念
- 情绪价值：解气/治愈/共鸣，结尾要有情绪落点
- 节奏：主歌 2-3s/镜，副歌 3-4s/镜，重复段必须换场景换机位
- 记忆点：全片一个贯穿梗（道具/角色/隐喻），不贪多
- 代入感：画面元素来自观众熟悉的生活
- 反转/爽点：中后段给一次"揭穿/打破"式转折

## 4. 段落纪律

- 每段镜头全片唯一（重复歌词→新镜头）
- 同一角色同一视角特写全片 ≤2 次
- 段间转场：0.35s 交叉淡化（唯美类）或硬切卡点（快节奏类）
- 每段必须有运动（禁止静态图幻灯片）
